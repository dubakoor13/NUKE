# NUKE conforming fuel-element physics: tabulated solid materials and coupled hydrogen momentum

This document describes *implemented Python reactor-core equations*, not
historical NASA physical validation. The output is conditional on user-supplied
thermophysical data and on valid subsonic hydrogen operating conditions.

## Code

- core_solid_material_tables.py — fuel/ZrC k(T), cp(T), exact heat capacity integral
- core_hex_conforming_hydraulics.py — steady 3D solid + 19-channel subsonic H2
  mass/momentum/stagnation-enthalpy/film-coefficient fixed-point coupling
- core_hex_conforming_fem.py — existing implicit 3D fuel/ZrC conduction,
  coolant enthalpy and optional signed kinetic energy correction
- run_core_hex_conforming_fem.py — one CLI for user-supplied spatial
  solid heating, fuel/coating material tables, and steady coupled hydraulics
- validate_core_solid_material_tables.py and
  validate_core_hex_conforming_hydraulics.py — executable code-level checks

## Material thermodynamics: no assumed NERVA reference tables

The new TabulatedCoreSolidLaw is a drop-in replacement for CoreSolidLaw.
For each material, supply SI arrays in an NPZ:

    temperature_k
    conductivity_w_m_k
    cp_j_kg_k

Density [kg/m³] is supplied independently, and currently taken constant.
All tables must be positive, finite and strictly ordered in temperature.
Temperature extrapolation is prohibited: attempts to solve outside a
table's range raise ValueError instead of silently inventing fuel data.

Within each tabulated interval, k(T) and cp(T) are piecewise linear.
The specific internal-energy change is computed as the EXACT integral
of this interpolant:

    u(T2) - u(T1) = integral_T1^T2 cp(T) dT.

The implicit backward-Euler heat capacity uses the secant

    cp_eff(Told,Tnew) = [u(Tnew)-u(Told)] / (Tnew-Told),

with the local cp(T) limit as Tnew→Told. This preserves the energy
storage law across property-table knot points. Thermal conductivity
is evaluated at the prism's current six-node average during Picard
linearization. Material density is not dynamically updated for thermal
expansion; that requires an additional thermoelastic/geometry model.

Both fuel and ZrC have independently selectable tables, and the CLI
does not bundle any nominal or alleged historical NERVA data.

For example (property NPZ inputs supplied by the operator, not
generated by this example):

    python -m ntr.nerva.run_core_hex_conforming_fem \
      build/element_channel_power_reconstruction.npz \
      --mesh-cache build/conforming_mesh.npz \
      --fuel-density-kg-m3 <rho_fuel> \
      --fuel-material-npz fuel_properties.npz \
      --coating-density-kg-m3 <rho_ZrC> \
      --coating-material-npz zrc_properties.npz \
      --inlet-temperature-k <T_inlet> \
      --initial-temperature-k <T_initial> \
      --hydrogen-density-kg-m3 <rho_H2> \
      --film-w-m2-k <h_wall>

Those placeholders must be replaced by independently justified physical
inputs. The CLI rejects ambiguous simultaneous table and constant-k/cp
options; use either form for each material.

## Coupled subsonic hydrogen momentum and thermal exchange

Use --couple-hydraulics --inlet-pressure-pa with the same CLI for
*steady* pressure/energy/heat-transfer iteration. This option requires
--hydrogen-model nasa7-h2. Additional controls include
--hydrogen-viscosity-pa-s,
--hydrogen-conductivity-w-m-k, and --hydraulic-roughness-m.

At each outer iteration:

1. Compute or update all 19 axial film-coefficient fields using the NUKE
   channel correlations for the candidate frozen NASA-7 hydrogen states.
2. Solve the actual continuous 3-D fuel/coating prism conduction equations
   plus axial fluid enthalpy with a single monolithic sparse matrix.
   Export wall heat rates for each axial H2 channel.
3. Call NUKE's existing solve_fuel_channel_compressible separately for each
   of the 19 streams, using the solved wall heat plus any directly deposited
   hydrogen nuclear power. That solver conserves steady mass, total
   (stagnation) enthalpy and axial momentum under its subsonic
   constant-area Darcy-friction approximation:

       G = mdot/A
       v = G/rho(T,p)
       mdot [(h_out+v_out²/2)-(h_in+v_in²/2)] = Q_wall + Q_direct
       p_in-p_out = G(v_out-v_in)
                  + f_D*(dz/D)*G*(v_in+v_out)/4

4. Reconstruct the signed change in kinetic-energy flux for each axial
   cell, and add an equal-and-opposite correction to the FEM hydrogen
   *static* enthalpy balance:

       Q_kinetic_to_static = -0.5 mdot (v_out²-v_in²).

   This is necessary: updating pressure while continuing to solve a
   static-enthalpy-only gas equation would otherwise silently violate
   steady stagnation-energy conservation.
5. Under-relax updated film coefficients and kinetic corrections and
   continue until the FEM hydrogen temperatures agree with the
   hydraulic momentum solution and the film/kinetic fixed points
   converge. Reject nonconverged, nonphysical pressure or choked/
   near-transonic conditions instead of inventing a fallback solution.

The converged code outputs the axial pressure/Mach/film fields,
friction and acceleration pressure changes, kinetic-energy
corrections, and fluid momentum/stagnation-energy numerical residuals.
They are written to conforming_core_hydraulics.npz. The JSON report
includes outer iteration count, maximum Mach, and temperature
inconsistency.

### Scope limitations

- Only STEADY quasi-1D compressible momentum is coupled to the conforming
  fuel-element thermal field. The H2 *inventory transient* option still
  exists in the original thermal FEM, but is not combined with
  quasi-steady kinetic-energy corrections. Attempting to combine
  those options is an explicit error; otherwise fluid kinetic
  accumulation would be omitted.
- Flow rates and inlet pressure/temperature are prescribed. No
  manifold flow-distribution network, pump, valves or feedback controller.
- Uses frozen molecular NASA-7 ideal H2. Does not support real-fluid
  hydrogen, dissociation, transonic/shock waves or chemical kinetics
  in this coupling.
- Uses the repository's simple friction/Nusselt screening correlations,
  not measured heat-transfer coefficients or historical NERVA film data.
- Does not compute OpenMC nuclear heating, neutron source convergence,
  evaluated hot cross sections, neutron-material thermal feedback or
  a validated critical reactor design.
