# Nuclear Thermal Propulsion models

This directory contains OpenMC-based nuclear thermal propulsion (NTP) models
built on top of the OpenMC source tree in this repository.

The first implementation is `ntr/nerva`, a NERVA-derived geometry demonstrator.
It is intended for neutronics workflow development and historical/educational
analysis, not as a flight reactor design.

See `ntr/nerva/README.md` for usage.
